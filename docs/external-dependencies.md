# 外部依赖与待确认项

以下信息未提供，因此原型使用适配器/演示值，不包含任何真实凭据：

1. 已完成主体认证的小程序 AppID、AppSecret 保管方式、服务器合法域名。
2. 微信支付商户号、API v3 证书/密钥、回调域名、退款和开票主体流程。
3. 历史订单样表字段、手机号质量、同一人多手机号/多微信的合并规则。
4. 腾讯会议套餐、主持人账号体系、会议创建是否人工完成；MVP 可先由运营录入特邀链接，不依赖会议 API。
5. 私有对象存储、CDN/水印要求、单文件大小与版权授权范围。
6. AI 服务供应商、数据是否允许出境/用于训练、敏感信息脱敏策略；未确认前只做可替换接口。
7. 管理员角色名单、需求披露审批责任人、审计留存期限。
8. 会员协议、隐私政策、内容版权、招聘/融资/并购信息发布的法务审核结论。
9. 微信订阅消息模板、用户授权时点、发送频率及报名/变更/会前/会后各模板内容。
10. 城市沙龙城市清单、单场容量/候补规则，半年与年度聚会的节奏和线下签到方式。
11. 飞书一次性迁入采用哪条路径：公司自建应用最小只读授权，或用户提供 HTML/Markdown/PDF/附件导出包；还需确认文件所有权和可迁移版权。只读路径已具备服务端连接与官方 API 适配边界，真实执行仍需在飞书控制台创建应用、配置最小只读权限、授予目标知识库资源读权，并通过部署平台私密注入 App ID/App Secret 与私有存储。迁入后撤销授权/删除原包并弃用飞书，不做持续同步。
12. 公司主体全称、统一社会信用代码、协议/开票主体，以及小程序和支付商户主体一致性。
13. 哪些商品/金额属于一年会籍、部分退款如何折算、重复/二次付款如何顺延、人工补录需要哪些凭证。
14. `left / removed / unknown` 是否一律使会籍失效，还是存在退群宽限期与重新入群恢复规则。
15. 同一人多手机号、多微信、手机号变更以及同一联系方式对应多人时的匹配优先级和人工合并权限。
16. 在职名片允许类型、正式大小上限、保留期限、撤回/注销删除 SLA、病毒扫描和私有对象存储供应商。
17. 公开资料审核角色、审核 SLA、退回原因码，以及“隐藏名册”是否必须审核后生效（当前原型要求审核）。
18. 在职核验角色和结论有效期；当前规则仅更新 CRM 在职核验子状态，不影响会籍或公开资料。

建议用户优先提供一份脱敏历史订单样表和现行会员规则；这两项决定首次绑定与续费迁移的准确性。
