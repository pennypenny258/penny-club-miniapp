# 从电脑导入资料

“从电脑导入资料”是当前资料迁移的首选路径；飞书一次性迁入继续保留为可选方案。所有电脑导入项默认进入待审核区，只有人工确认发布后的资料才会出现在会员端。

## 现在怎么用（5 步）

1. 打开运营后台，进入“资料与导入 → 从电脑导入资料”。
2. 把一个或多个文件拖到上传区，或点击上传区选择文件；不强制准备 CSV。
3. 选择资料库分栏，按需填写来源说明（默认“本地迁入”）、下载开关和“需要人工确认分类”；文件标题可逐项修改。
4. 点击“上传到待审核区”。在下方队列检查标题、分类、下载设置、安全元数据和版权；需要时先保存修改。
5. 可填写“关键词标签”：支持中文逗号、英文逗号或换行分隔，自动去重，每项最多 10 个、每个最多 24 字符。标签只有在资料发布后才会进入会员端搜索。

## 自动建议标签（可修改）

上传或创建条目后，服务端会默认生成 3–8 个候选标签。运营可删除候选、一键采用、继续编辑或重新生成。候选不会自动写入资源；只有点击“保存修改/保存标签”后的最终标签才入库。

当前安全 MVP 的分层边界：

- 当前未配置 AI、OCR、转写或稳健文本提取，页面固定标记“规则建议，待确认”。
- 规则只使用安全可得的标题、资料分类和文件名元信息，可识别软件、AI、融资、并购、招聘、行业报告、回放、群聊精华等可靠主题词。
- PDF/DOCX/Markdown/TXT 尚未配置稳健解析，不声称已读取正文；扫描 PDF 仍需 OCR。
- 图片明确显示“需 OCR”，音视频明确显示“需转写/帧 OCR”，不会猜测内容。
- 手机号、邮箱、网址、Secret/token/API key 形式的文本不会进入建议标签。

正式 AI 边界位于服务端 `TagSuggestionService` 与供应商适配器。浏览器不接收 API key；当前默认适配器为 disabled，不发起任何外部 AI 请求。
5. 确认来源版权、分类和文件安全后点击“确认并发布”；不需要的条目可跳过。已发布资料才会进入会员端对应分栏。

如果暂时没有文件，可用“先建条目，稍后补文件”。此类条目标记为“待补附件”，下载固定关闭；本 MVP 尚未实现向既有无文件条目补传附件，可跳过旧条目后重新上传，正式版应增加版本化补附件能力。

## 支持格式与演示限制

| 格式 | 处理方式 |
|---|---|
| PDF、DOCX、XLSX、PPTX | 私有保存；不执行宏、公式或嵌入内容，不承诺在线预览 |
| MP4、MP3、M4A | 私有保存；不自动转码、转写或生成封面 |
| PNG、JPG、JPEG | 私有保存；不做 OCR |
| Markdown、TXT | 拒绝明显脚本和公式注入前缀；不自动解析为网页 |
| ZIP | 只作为附件包保存，不解压、不递归执行内容 |

仅接受白名单扩展名与匹配的 MIME/基础文件签名；宏文件、脚本、可执行文件、CSV 等不在允许范围。单文件最多 25MB，单批最多 20 个文件且总计不超过 100MB。文件名会安全化，后台/API/日志不返回原始文件名、私有路径或存储键。

当前“安全确认”是运营人工确认，不代表系统已完成病毒扫描。内容预览、转码、Office 公式检查、压缩包内容检查和恶意文件扫描均未配置，页面不会伪装为已完成。

## 六个资料分栏建议

- 线上分享回放：会议回放视频、音频及会后资料。
- 研究报告：行业报告、投研报告和研究笔记。
- 群聊精华：经运营整理、脱敏并确认可发布的群聊摘要。
- 书籍：书籍资源、阅读材料及书单说明。
- 常用文件模板：数据源、工具说明、表格或演示模板。
- 福利更新与领取：会员福利规则与领取说明；避免上传公开兑换码或联系人。

批量上传可直接选择“研究报告”或“群聊精华”，会员端也分别筛选。历史 `reports_digest` / `reports_digests` 合并值只在既有类型或标题/标签能明确判断时自动兼容；无法判断的旧项会显示“待分类（不可发布）”，不会擅自公开或批量归类。

`downloadEnabled` 只决定是否出现下载入口。开启后仍需有效会籍和生产私有签名下载；任何会员接口都不得返回文件路径、存储键或来源内部信息。

已发布资料默认具有受控“打开查看”入口，与 `downloadEnabled` 无关。当 PDF、Office、视频等文件尚未接入安全预览/转码时，阅读入口只展示已发布的标题、摘要和标签，并明确说明“在线预览能力待配置”；不会伪造预览成功，也不返回私有存储定位符。

## 本机演示与正式上线边界

本机演示把附件写入被 Git 忽略的私有目录，文件本身可留在本机，但批次、审核状态和资料记录仍在 Node.js 进程内存中；重启服务后会恢复演示种子状态，不能作为正式迁移成果。

正式运行前必须完成：持久化数据库与迁移脚本、私有对象存储及 Node 代理下载、病毒/文件类型/大小/压缩包安全检查、备份恢复、保留与删除机制、版权和来源确认留痕、生产 RBAC 与审计。未完成这些条件前，只可用于匿名测试资料的流程演练。

CloudBase PG 的下一阶段准备见 `cloudbase-private-resource-storage.md`。该边界选择 Node 服务端直传和代理下载，不让浏览器/小程序获得对象键、`service_role` 或预签名地址；目前尚未接入本页面的真实上传路由。
