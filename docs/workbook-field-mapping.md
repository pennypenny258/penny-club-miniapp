# 本地工作簿字段映射说明（不含数据行）

本说明依据已确认的工作簿字段结构编制，不包含、摘录或推断任何真实数据。项目目录当前未发现可读取的工作簿文件，因此正式导入前仍需用脱敏表头复核工作表差异。

## “创投会员名册（自愿登记）”

| 原字段 | 目标处理 | 是否公开 |
|---|---|---|
| 姓名 | 内部 CRM 身份辅助；不能自动成为公开名称 | 否 |
| 机构 | 自愿名册候选字段，需单独同意和审核 | 条件公开 |
| 联系方式 | 加密私密字段/匹配令牌；对接仍走申请 | 否 |
| 行业、兴趣、阶段、城市、专业领域、简介 | 自愿名册候选字段 | 仅同意且审核后 |
| 备注 | 内部 CRM 运营备注 | 否 |
| 会员确认的公开显示名 | `public_display_name`，需单独收集/确认 | 条件公开 |
| 来源工作表 | `source_sheet`，用于相似历史表去重 | 否 |

多个相似历史工作表不得直接合并。先比较表头版本、来源时间和行指纹；重复或冲突记录进入人工复核，原表不覆盖新表或反向覆盖。

## 微信小店订单

| 原字段 | 标准字段 | 处理 |
|---|---|---|
| 收件人姓名 | 姓名匹配线索 | 仅用于 CRM 候选匹配，不回显 |
| 订单发货时间 | 入群时间线索 | 主要作为可能入群时间；缺失时待人工补充 |
| 收件人手机 / 收件人手机号 | 手机匹配线索 | 仅用于受控会员匹配，不回显 |
| 商品价格（单件/实际单件/实际总共） | 身份价格线索 | 按 200 / 666 / 799 / 499 元生成四档候选；不回显原价 |

订单号、地址、留言、商品名、订单状态、下单时间、实付/收款、物流及其他配送字段自动忽略，不产生“未知字段”错误。若存在退款/售后列，只生成安全汇总计数。正式受控接入若确需幂等去重，应在导入边界生成不可逆记录指纹，不在页面、日志或报告展示原值。

三类付款来源统一使用标准金额候选：200 元天使轮股东、666 元 A1 轮股东、799 元 A2 轮股东、499 元荣誉董事。未命中、缺姓名/手机号/发生时间或出现可能退款时进入人工核对；金额命中也只生成身份候选，不能直接确认会籍。
