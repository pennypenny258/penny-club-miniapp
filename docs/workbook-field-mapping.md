# 本地工作簿字段映射说明（不含数据行）

本说明依据已确认的工作簿字段结构编制，不包含、摘录或推断任何真实数据。项目目录当前未发现可读取的工作簿文件，因此正式导入前仍需用脱敏表头复核工作表差异。

## “创投会员名册（自愿登记）”

| 原字段 | 目标处理 | 是否公开 |
|---|---|---|
| 姓名 | 内部 CRM 身份辅助；不能自动成为公开名称 | 否 |
| 机构 | 自愿名册候选字段，需单独同意和审核 | 条件公开 |
| 联系方式 | 加密私密字段/匹配令牌；对接仍走申请 | 否 |
| 行业、兴趣、阶段、城市、专业领域、简介 | 自愿名册候选字段 | 仅同意且审核后 |
| 备注 | 内部 CRM 运营备注 | 否 |
| 会员确认的公开显示名 | `public_display_name`，需单独收集/确认 | 条件公开 |
| 来源工作表 | `source_sheet`，用于相似历史表去重 | 否 |

多个相似历史工作表不得直接合并。先比较表头版本、来源时间和行指纹；重复或冲突记录进入人工复核，原表不覆盖新表或反向覆盖。

## 微信小店订单

| 原字段 | 标准字段 | 处理 |
|---|---|---|
| 订单下单时间 | `order_placed_at` | 受控付款证据字段，不回显 |
| 订单状态 | `order_status` | 映射到 paid/completed/partial_refund/cancelled/refunded/pending |
| 收件人手机 | `recipient_phone` | 仅用于受控会员匹配，不回显 |
| 实际支付金额 | `actual_paid_cents` | 转换为整数分，受控存储 |
| 实际收款金额 | `collected_cents` | 与退款共同判断净收款，受控存储 |
| 支付时间 | `payment_at` | 付款证据时间，受控存储 |
| 商品名称 | `product_name` | 匹配用户确认的会籍产品规则 |
| 退款金额 | `refund_cents` | 全退排除、部分退款人工复核 |
| 导入批次 | `source_batch` | 由导入流程生成/填写 |

若工作簿还含订单号、地址、支付凭据或其他配送字段，当前模板不接受这些字段。正式受控接入若确需幂等去重，应在导入边界生成不可逆记录指纹，不在页面、日志或报告展示原值。

实际工作簿中的中文订单状态不应在代码中猜测。预检 API 支持本批次 `statusMapping`（原值到标准状态）以及 `eligibleProducts`（用户确认的会籍产品列表）；未配置产品规则时只能生成“待人工复核候选”，不能确认有效付款或会籍。
