# 运营后台上线准备报告

更新时间：2026-08-05。范围仅限运营后台、服务端边界与生产准备；未重做会员端视觉。

## 结论

后台 MVP 已形成六模块、可执行队列、四角色最小权限、高风险确认、幂等防重复、安全列表响应和审计闭环。当前仍是匿名内存演示环境，不能直接作为生产系统发布；数据库、私有对象存储、真实后台认证及微信/腾讯会议等外部能力完成验收前，发布状态固定为“未放行”。

## 角色与最小权限

| 角色 | 允许 | 禁止 |
|---|---|---|
| 系统管理员 | 角色、配置、高风险最终操作及全量安全视图 | 不作为日常共享账号 |
| 运营人员 | 会员、付款、续费、导入、活动、迁入和撮合日常处理 | 不读取或修改密钥，不管理角色 |
| 审核人员 | 公开名册、在职安全元数据、内容和需求审核 | CRM、付款域、密钥与原始附件 |
| 审计人员 | 工作台、上线检查与审计只读 | 所有业务写操作及 CRM/付款明细 |

演示环境以 `x-demo-role` 验证权限矩阵；这不是生产认证。生产必须改为公司身份源 + 服务端会话 + 数据库角色绑定，并在发布检查中令 `ADMIN_AUTH_MODE=external_session`。未知角色会被拒绝，不能回退为管理员。

高风险动作包括会籍/CRM 变更、付款结论、续费报价、公开名册发布、在职终审、内容发布、活动取消、需求终审、Agent 分发、飞书断开和批量执行。服务端同时要求明确动作确认标识和幂等键，重复请求会被拦截；生产应把幂等记录写入数据库并设置有效期。

## 日常运营能力

- 全局待办覆盖会籍、公开资料、在职核验、付款复核、导入异常、通知重试、需求终审和申请分发。
- 列表提供关键词和状态筛选、结果计数与明确空状态。
- 通知异常支持单条和批量预检/执行；批量上限 100 条，只允许“开始审核/排队重试”等非最终披露动作。
- 关键队列已提供处理按钮，服务端仍逐项复核权限与状态，不能依赖前端隐藏。
- CRM、付款列表、名片核验、知识资料和需求列表均使用字段白名单；不返回付款原文、联系方式、名片、飞书来源链接/目录、附件路径、存储键、密钥或需求高敏字段。

## 演示与生产边界

| 能力 | 当前演示 | 生产要求 |
|---|---|---|
| 数据库 | 进程内数组，重启还原 | PostgreSQL 事务、迁移版本、连接池、只读副本按需 |
| 文件 | 演示不存真实名片；本机迁入可用私有目录适配器 | 私有对象存储、签名下载、病毒/类型/大小检查、加密与删除 SLA |
| 密钥 | 仅环境变量名样例，无真实值 | 部署平台 Secret 管理、轮换、最小读取和泄露告警 |
| 日志 | 安全审计摘要 | 结构化日志、字段脱敏、不可变审计、访问审批和留存策略 |
| 备份 | 无 | 数据库 PITR、对象版本/跨区备份、季度恢复演练、明确 RPO/RTO |
| 监控 | 健康接口和本地控制台 | 可用性、错误率、队列积压、支付回调、通知失败、存储扫描和审计异常告警 |
| 后台认证 | 演示角色请求头 | 公司 SSO/受控账号、MFA、服务端会话、RBAC、离职撤权和定期复核 |

生产配置变量名见 `config/server.env.example`，不得填写真实值后提交版本库，也不得把 Secret 发到聊天或普通网页。

## 外部依赖验收

### 飞书一次性迁入

- 创建公司自建应用并配置当时官方控制台显示的最小只读权限。
- 给目标知识库/资源授予应用读权，在部署密钥中注入凭据。
- 后台测试连接、迁入一份非敏感测试目录，验证目录、正文、附件、待审核、失败重试。
- 审核完成后断开来源，撤销资源读权并删除/轮换密钥；不启用持续同步。

### 微信登录、支付与订阅消息

- 真机验证公司主体 AppID、登录绑定、UnionID/多身份合并和注销流程。
- 支付验签、幂等、退款、重复回调、补单、二次付款顺延和对账必须在沙箱/测试商户演练。
- 每类订阅消息验证授权时点、模板、拒绝授权、频控、失败重试和实际回执；报名不等于腾讯会议席位。

### 腾讯会议与文件安全

- 确认套餐容量、主持人、人工录入或 API 模式；特邀链接只在服务端加密保存并通过既有三重门禁返回。
- 文件上传验证扩展名与 MIME 双检、大小、病毒/恶意文件、压缩包路径穿越、私有存储、短时签名、水印（如需）、保留和删除。

### 隐私、协议与授权留痕

- 确认公司主体、隐私政策、会员协议、内容版权、招聘/融资/并购免责声明和版本号。
- 对公开名册、订阅消息、名片核验、敏感材料披露分别保存目的、版本、时间、同意/撤回和证据引用；撤回后按 SLA 停止使用并删除。

## 上线执行清单

1. 冻结 PRD 状态机、角色责任人与会籍合并规则。
2. 建立 PostgreSQL 生产库，执行 schema 迁移、约束/索引/加密审查和回滚演练。
3. 接入私有对象存储和文件安全流水线，验证权限越权与删除。
4. 接入生产后台认证、MFA、服务端会话与数据库 RBAC，删除演示角色头。
5. 配置结构化脱敏日志、监控告警、不可变审计、备份和恢复演练。
6. 在隔离测试环境完成飞书一次迁入；审核后撤权断开。
7. 完成微信开发者工具/真机的登录、支付、订阅消息和隐私授权验收。
8. 完成腾讯会议容量、链接门禁、活动取消/变更和会后归档验收。
9. 执行自动化回归、安全扫描、越权测试、并发/幂等测试和运营 UAT。
10. 发布前运行 `npm run release:check`；所有外部项、用户决策和演示配置清零后方可放行。

## 仍需用户决策的最小事项

1. 部分退款如何折算会籍；重复/二次付款如何顺延；非小店人工续费需要哪些证明和复核人。
2. `left / removed / unknown` 对会籍的精确影响、退群宽限和重新入群恢复规则。
3. 需求人工终审、Agent 分发、需求方披露确认的责任人、SLA、替补与双人复核门槛。
4. 公开资料/在职核验审核 SLA、名片保留期限和删除 SLA。
5. 审计与业务数据留存期限、备份 RPO/RTO、文件大小/类型和水印政策。
