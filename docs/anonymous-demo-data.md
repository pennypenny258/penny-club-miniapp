# 匿名演示数据说明

## 用途与边界

本项目种子数据只服务于视觉原型、内部试用和运营流程演练。人物使用不可识别的演示代号，组织名称明确标注为虚构；记录之间仅为产品流程需要而关联，不对应、不复制，也不得用于推断任何真实会员、企业或交易。

禁止把真实姓名、联系方式、微信身份、订单号、地址、付款凭据、会议特邀链接、名片内容、附件路径或高敏感商业材料写入种子数据、前端、日志和测试报告。

## 覆盖状态

- 会员域：有效、临期、过期、待核验、冻结、退款待复核；CRM 核验和公开名册保持独立。
- 公开名册：已同意并发布、隐藏、待审核；资料更新包含提交、审核中、退回补充和已发布。
- 在职核验：仅提供文件类型、大小分级和状态元数据，覆盖提交、审核中、通过、退回；没有文件内容、名称或存储键。
- 知识迁移：十类飞书目录均有产品落位；展示标签、权限、来源确认、迁移完成和待复核状态。
- 活动：线上、线下、混合；报名中、满额候补、进行中、结束归档、取消和草稿，以及通知排队、已发送演示、重试、模板待配置状态。
- 需求：招聘、融资、并购；覆盖 AI 初筛、人工终审、匿名发布、退回/拒绝、申请、Agent 筛选、需求方确认和分级披露。
- 付款与导入：小店证据候选、人工补录、二次付款、部分退款复核、全额退款/取消排除、异常修正及多类导入批次。任何付款证据都不能单独激活会籍。
- 运营：看板、导入工作项、两类审核队列、活动通知和审计日志均有可浏览记录。

## 安全验收

回归测试必须确认：非有效会员无法访问受控知识库与名册；会员 API 不返回 CRM、付款、名片或需求敏感字段；会议链接仍受“有效会籍 + 已报名 + 开放时间窗”三重门禁；公开名册只返回明确同意、人工通过且未隐藏的资料；发布预检继续阻止演示配置进入生产。
