# 完整需求覆盖与缺口审查

审查基线：公司主体运营、约 2000 人付费会员、移动端微信小程序、运营管理后台，以及现有飞书目录迁移。

| 已确认需求 | 产品落位 | 原型状态 | 生产缺口 |
|---|---|---|---|
| 微信登录绑定 + 会籍有效期 + 群内状态 | `users / memberships`；我的会籍；后台会员页 | 会籍与群状态门禁可运行 | 微信主体账号、unionid 合并规则 |
| CRM、自愿名册与订单证据治理 | CRM 核验、公开名册审核、付款证据、最终会籍四个独立后台域 | 小店 CSV 安全预检、自愿名册独立审核和双状态总览可运行 | 脱敏表头、去重/冲突/回滚及会籍合并规则 |
| 年度手动续费、标准价与专属价 | 续费方案、订单 | 个性报价及续期基准规则已建模 | 微信支付、退款/补单/开票流程 |
| 六类知识库 | 使用说明、行业报告、群聊精华、线上回放、书籍、数据源、工具 | 全部有演示落位 | 飞书导出、版权、存储与水印 |
| 无联系方式会员名册、申请对接 | 独立自愿名册、同意、人工审核、会员对接 | 仅审核通过档案进入会员端，CRM/订单无同步路径 | 公开显示名和撤回/更新规则 |
| 招聘/融资/并购 | 需求中心 | 三类匿名卡片可运行 | 真实表单字段和分类词表 |
| AI 初筛 + 人工终审 | AI 初筛、需求人工终审 | 状态与审核接口已建模 | AI 供应商、提示词、人工 SLA |
| 会员申请 + Agent 二次分发 | 需求申请 / Agent 分发 | 申请及分发接口已建模 | Agent 角色、路由和责任人 |
| 发布者决定分级披露 | 披露策略、授权表 | 匿名接口会剔除后台敏感字段 | 确认通知、授权有效期和撤回规则 |
| 个人隐私/高敏材料不得公开 | 服务端字段白名单、私有存储设计 | 公司名、交易条款不会进入公开接口 | 加密密钥、存储、下载水印与审计策略 |
| 线上/线下/混合活动 | 主题讨论、城市沙龙、半年/年度聚会 | 四类演示活动已落位 | 城市计划、线下容量/候补规则 |
| 有效会员报名、线上不保留席位 | 活动报名 | 服务端会籍门禁与提示可运行 | 腾讯会议套餐容量 |
| 特邀链接会前限时展示 | 会议链接接口 | 会籍 + 报名 + 时间窗三重门禁可运行 | 真实链接录入/API 方式 |
| 报名/变更/会前/会后通知 | 通知任务 | 四个触发点已建模 | 微信订阅消息模板及用户授权 |
| 回放/纪要/资料归档 | 活动关联知识库资源 | 回放类资料与活动关联已建模 | 录制版权、上传与发布时间 |
| 后台全域管理与审计 | 后台导航及审计日志 | 各域可浏览，关键动作留审计 | 完整 CRUD、RBAC、双人复核 |
