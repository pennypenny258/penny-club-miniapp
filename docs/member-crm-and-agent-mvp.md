# 会员 CRM 与需求对接 Agent MVP

本轮只收敛两个入口：后台 **会员 → 会员 CRM 库**，以及后台 **需求与撮合** / 会员端 **Agents**。资料库、活动、回放和管理员恢复不在本轮扩展。

## 会员 CRM 主档案

核心核对字段为微信群昵称、微信号、手机号、真实姓名。历史数据可以缺失，导入后进入“待补全”，不能假设完整。微信号、手机号、真实姓名、名片、内部备注、付款与群状态只在内部 CRM 使用，会员端和公开名册接口不返回。

会籍档位为：天使轮股东 200 元、A1 轮股东 666 元、A2 轮股东 799 元、荣誉董事 499 元。499 元可产生荣誉董事候选；运营也可用受邀、免单、无付款记录或人工修正原因手动确认。付款和人工档位都不能单独激活会籍，大群状态 `in_group` 是最终硬门禁。

会籍有效期按 `YYYY-MM` 保存。到期月月底统一通知；续费从原到期月顺延，不从付款月重算。标签到期但仍在大群且尚未通知续费时，显示“待续费跟进 / 仍暂时有效”。首次支付、逐人续费价、通知状态、最近通知月、付款线索状态与付款月均可独立维护，未付不直接判失效。

累计在籍时长由“人工确认的历史累计月数 + 当前在群区间”构成，显示为 X 年 X 月。未来可新增多段进出群区间；MVP 不要求追溯全部历史。

基础 CRM Excel / CSV 可识别昵称、备注名、到期月份、续费价格、通知状态、通知日期、付款状态、付款日期、手机号、付款姓名、操作备注，以及可选的群状态、微信号、真实姓名、会员等级、首次入群月份、累计在群月数。至少有一个昵称、备注名、微信号、手机号或姓名线索即可进入人工队列；手机号/微信号缺失是逐行待补，未付不判失效。“待确认”到期月会保留在私有人工补齐边界，不作为日期错误、不自动推断有效期。当前后台只做脱敏预检且不写内存；三类付款来源仍只生成匹配线索。

预检完成后可建立“脱敏批次演练”：每行只显示行号、缺项、群状态类别、付款状态类别和档位候选，可练习补齐清单、唯一匹配、冲突处理或新建待补主档。演练不保存原始值、不修改会员主档、不激活会籍；正式确认按钮在真实后台会话、CloudBase 网关、审计与幂等全部就绪前持续禁用。

## 公开名册与内部 Agent 标签

公开名册与 CRM 完全独立：

- 完全不公开：不进入公开名册，仍可用匿名摘要参与私密匹配。
- 自选公开：成员选择字段并同意，运营审核后公开。
- 完全公开：也只公开简省白名单字段。

公开白名单固定为公开姓名或昵称、公司、职位、机构类型、城市、赛道、职业或资源标签、自我介绍、合作偏好。手机号、微信号、付款、群状态、名片、内部 CRM 与 Agent 内部标签永不公开；联系方式只通过申请对接。

Agent 对话产生的匹配标签默认内部，可由运营修正或删除，记录来源为 Agent / 人工和更新时间。它不自动进入公开名册，也不释放联系人。首次使用隐私说明需要覆盖“为受控匹配生成内部标签”这一用途。

## 需求对接 Agent

Agent 只处理投资、融资、并购、招聘、招商。文本可进入人工待审；真实语音转写与 AI 尚未配置，界面必须明确提示。规则建议或未来 AI 只生成结构化草稿、敏感提示和候选标签，不能自动公开、定向推送或泄露信息。

审核员可以要求补充、拒绝、归档、匿名公开发布或生成定向候选。定向候选必须在“人、机构、角色、事项”四项中至少明确三项，且只能由运营人工发送；同一机会 14 天内不重复提醒，未回复不反复催促。

申请对接必须分别说明“我是谁、为什么联系对方、希望讨论什么”，拒绝泛泛的“想认识 / 加微信”。需求方可同意介绍、要求补充或婉拒。双方同意前不释放联系方式；MVP 同意后仍由运营代为转交。

招聘只接受内部群友提交或背书。允许展示经许可的公司信息和公开投递渠道；直接投递不需要中间申请，但内推或代转简历仍走完整对接流程，推荐人联系方式不公开。

## 上线边界

当前只使用匿名内存演示数据。真实上线仍需微信联合登录、持久化数据库、CloudBase 后端网关、私有名片存储、AI / ASR 服务、微信支付、通知发送与运营 SLA；任一配置缺失时不得回退到演示身份或内存数据冒充生产成功。
